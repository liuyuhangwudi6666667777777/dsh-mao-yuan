# dsh-mao-yuan · 毛选溯源参谋

用《毛泽东选集》的方法论拆解现实问题，**每个判断都能翻回原文出处**。

不是"毛泽东聊天机器人"，也不是语录复读机。它做三件事：

1. **先调查再发言** —— 信息不足时先问 3–5 个具体问题，不急着给结论
2. **强制引用** —— 任何"毛选怎么讲"的断言必须先检索原文，检索不到就直说没谈过
3. **区分事实与判断** —— 每个判断都带反证条件

称呼同志，不说鸡汤。

---

## 为什么做这个

GitHub 上已有 6+ 个"毛选 skill"项目（[qiushi-skill](https://github.com/HughYau/qiushi-skill) 3819★、[maoxuan-skill](https://github.com/leezythu/maoxuan-skill) 1229★、[Maoxuan-Changzheng](https://github.com/zhangtianruiwork-droid/Maoxuan-Changzheng) 447★ 等），但它们**全部停在"提示词包 + 聊天框"**：

- 模型可以随口说"毛泽东说过……"，用户无法分辨真假
- 没有检索，就没有溯源，幻觉是产品级事故

本项目补的就是这一层：**关键词检索 + 原文段落定位 + 强制引用**。

## 快速开始

```bash
# 1. 拉语料（不入库，见下方「版权」）
node scripts/fetch-corpus.mjs

# 2. 验证检索质量
node scripts/eval.mjs --verbose

# 3. 跑单元测试
npm test

# 4. 装进 DSH
dsh plugin --profile web add link:<本目录绝对路径>
```

装好后**新建会话**生效。

## 架构

```
用户提问
   ↓
┌─ 提示词层 ─────────────────────────────┐
│ 称呼同志 / 先追问 / 不说鸡汤 / 强制引用 │  systemPrompt.section(order=10)
└────────────────┬───────────────────────┘
                 ↓ 模型判断需要取证
┌─ 工具层 ───────▼───────────────────────┐
│ mao_search(query, limit)               │  ctx.tools.register
│   → BM25 关键词检索                     │
│   → 返回 篇目/章节/段落号/原文          │
│   → 未命中 → 明确"没有直接谈这个"       │
└────────────────┬───────────────────────┘
                 ↓
┌─ 语料层 ───────▼───────────────────────┐
│ 229 篇 → 2065 段（已剔除注释与题解）    │  本地 corpus/，gitignore
└────────────────────────────────────────┘
```

**关键设计**：检索是**模型可调用的工具**，不是自动塞上下文。这样模型能自己决定查几次、换什么词，比一次性灌 Top-K 更准，也让"未命中"成为可观测信号。

## 检索实现

零依赖，纯 Node。

| 组件 | 做法 | 理由 |
|---|---|---|
| 中文分词 | 无词典 **bigram** | 插件要轻、可离线；bigram 不会因缺词典切错专名 |
| 排序 | **BM25**（k1=1.2, b=0.75） | 中文短段落常用值 |
| 篇名加成 | idf 加权后**按篇名长度归一化** | 否则《工人阶级与资产阶级的矛盾是国内的主要矛盾》这类长标题会霸榜 |
| 短语加成 | 查询连续子串原样出现在正文则加分 | bigram 会切出"与自""我批"这类跨词噪音，短语加成把真正的"自我批评"捞回来 |

### 一个必须处理的坑：注释不是原文

语料里 169/229 篇带 `------------------` + `注　　释` 注释块，179 篇带 `>` 题解。这些是**人民出版社编辑作品**，既不是毛泽东原文，也不在公有领域。

不过滤会导致：答案张冠李戴（《为人民服务》Top-1 曾是张思德的脚注），以及版权越界。

`stripApparatus()` 会切掉两者：段落数 2508 → 2065，剔除 443 条。

### 评测结果

```
段落数：2065
词表规模：102853
命中率：20/20 = 100.0%（阈值 85%）
```

评测判据刻意选成**可客观验证**的：Top-5 中至少一段的「篇名 + 正文」包含指定关键短语。

不用"必须命中某个篇目"——同一主题在《毛选》里天然分散在多篇（"批评与自我批评"在《整顿党的作风》《论联合政府》都讲，也在大量讲话中出现），按篇目判会误伤正确结果，还会诱导过拟合。

## 版权（重要）

- 《毛选》单篇著作的保护期至 **2026-12-31** 届满（作者 1976 年逝世 + 50 年）。
- 但**选集的编排、校订、注释是人民出版社的编辑作品**，不受此限。
- 因此：**全文不入库、不打进安装包**，由使用者本地运行 `fetch-corpus.mjs` 获取。
- 仓库只存代码、索引结构与短引。

语料来源：[weiyinfu/MaoZeDongAnthology](https://github.com/weiyinfu/MaoZeDongAnthology)（229 篇正文 Markdown）。

## 项目结构

```
dsh-mao-yuan/
├── cordis.patch.yml      # 挂进 host Loader
├── package.json          # dsh.bundle.patch 声明
├── scripts/
│   ├── fetch-corpus.mjs  # 拉语料（走 tarball，raw.githubusercontent 常被重置）
│   └── eval.mjs          # 检索质量评测，低于阈值退出码非 0
├── src/
│   ├── index.js          # 插件入口
│   ├── corpus.js         # 装载 + 剥离注释题解 + 段落切分
│   ├── tokenize.js       # 无词典 bigram
│   ├── bm25.js           # BM25 + 篇名/短语加成
│   ├── tool-search.js    # mao_search 工具
│   └── prompt.js         # 提示词（同志/先追问/不说鸡汤/强制引用）
├── test/                 # 17 个单元测试
└── corpus/               # 语料（gitignore，不入库）
```
